# Template Reference

## Email Templates

Override in `templates/account/email/`:

- `email_confirmation_subject.txt`
- `email_confirmation_message.txt`
- `email_confirmation_signup_message.txt`
- `password_reset_key_message.txt`
- `password_reset_key_subject.txt`

## Page Templates

- `account/login.html` — login form
- `account/signup.html` — registration form
- `account/email.html` — email management
- `account/password_change.html` — password change
- `account/password_reset.html` — password reset
- `socialaccount/login.html` — provider selection

See [official template docs](https://docs.allauth.org/en/latest/templates.html) for full list.
